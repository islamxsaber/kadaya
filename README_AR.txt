نظام متابعة القضايا - نسخة iPhone PWA
الإصدار: 1.0.0

طريقة الرفع إلى GitHub Pages:
1) فك ضغط الملف.
2) ارفع محتويات المجلد إلى مستودع GitHub (index.html يجب أن يكون في جذر الموقع المنشور).
3) من Settings > Pages اختر الفرع والمجلد الذي يحتوي الملفات.
4) افتح رابط GitHub Pages من Safari على iPhone.
5) Share > Add to Home Screen.

مهم:
- قاعدة البيانات تُنشأ تلقائياً عند أول تشغيل وتُحفظ محلياً في المتصفح.
- البرنامج يعمل Offline بعد أول تحميل ناجح بفضل Service Worker.
- لنقل البيانات بين الكمبيوتر وiPhone استخدم: النسخ والدمج > تصدير قاعدة البيانات / استيراد ودمج.
- المرفقات تُخزن مشفرة داخل قاعدة التطبيق، وتُفك عند المعاينة أو التصدير.
- إشعارات iPhone أثناء إغلاق PWA تحتاج Web Push Server؛ النسخة الثابتة المرفقة لا تحتوي خادماً خارجياً. استخدم زر «إضافة للتقويم» للتذكيرات المهمة كي يتولى iOS التنبيه حتى عند إغلاق البرنامج.
- لا تحذف بيانات Safari للموقع قبل تصدير نسخة احتياطية.
